# Security policy

Please [report vulnerabilities privately through GitHub Security Advisories](https://github.com/wintc23/web-agent-mate/security/advisories/new). Include the affected version, reproduction steps using synthetic data, and the potential impact. Do not include API keys, private page content, or other secrets in a public issue.

Only the latest release receives security fixes. The project treats webpage content as untrusted data, limits Native Messaging frames to 1 MiB, and restricts the native host manifest to one explicitly configured extension ID, using the project's fixed ID by default.
