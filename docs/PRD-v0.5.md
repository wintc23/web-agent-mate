# WebAgentMate v0.5 产品需求文档：统一智能体体验

> 文档状态：Implemented / Final
>
> 更新日期：2026-09-04
> 产品形态：Chrome Manifest V3 侧边栏扩展 + 可选 Native Bridge

## 1. 产品定义

WebAgentMate 是运行在 Chrome 侧边栏中的单一网页智能体。用户只需描述目标，智能体自行判断应该直接回答、解释、总结、翻译，还是调用浏览器工具完成任务。

产品不再提供“提问 / 执行”模式，也不要求用户理解模型内部的工具选择过程。远端与本地仅表示推理来源和可用工具不同，不表示两套产品体验。

## 2. 核心原则

1. **一个智能体**：所有请求进入同一消息协议、同一对话历史和同一任务循环。
2. **模型选择工具**：用户描述意图，智能体按需选择回答或浏览器动作。
3. **Bridge 是增强项**：未安装或未启用 Bridge 时，远端智能体仍可完整使用扩展内建工具。
4. **能力透明**：远端 / 本地切换只改变模型、数据路径和工具范围；不可用项说明缺失条件。
5. **风险分级**：读取、总结、翻译、滚动、填写和选择可自动完成；点击进入对话内确认；敏感操作禁止。
6. **对话连续**：追问、任务结果和批准后的继续执行共享最近对话历史。
7. **用户语言优先**：回答、行动理由、错误恢复提示均使用当前界面语言。

## 3. 用户体验目标

- 用户打开侧边栏后只看到一个输入框，不需要先选模式。
- 用户可以直接输入“总结这个页面”“翻译成中文”“点击文档入口”“这里是什么意思”。
- 回车发送，Shift+Enter 换行；输入法组合态不得误发送。
- 运行中发送按钮原位变成停止按钮，停止后不得继续执行迟到动作。
- 上下键仅在第一行 / 最后一行边界浏览最近 50 条已发送内容。
- 输入框旁只显示当前远端模型或本地 Agent 的切换入口。
- Orca Free 额度或上下文上限触发时自动打开模型选择弹窗。

## 4. 能力矩阵

| 能力 | 远端 OrcaRouter，无 Bridge | 远端 OrcaRouter，有 Bridge | 本地 CLI Agent |
|---|---:|---:|---:|
| 自由问答 / 解释 | 可用 | 可用 | 可用 |
| 页面总结 / 要点提取 | 可用 | 可用 | 可用 |
| 页面翻译 | 可用 | 可用 | 可用 |
| 读取页面与可交互元素 | 可用 | 可用 | 可用 |
| 滚动、填写、选择 | 可用 | 可用 | 可用 |
| 点击建议与用户批准 | 可用 | 可用 | 可用 |
| 任务停止 | 可用 | 可用 | 可用 |
| 本地 Codex / Claude / Coco | 不可用 | 可用 | 可用 |
| Bridge SQLite 任务记录 | 不可用 | 可选 | 可用 |

结论：Bridge 缺失只能令“本地 CLI Agent”不可选，不能令远端浏览器工具、总结、翻译或 Agent 循环不可用。

## 5. 信息架构

```text
WebAgentMate
├── 对话页
│   ├── 顶栏：连接状态 / 设置
│   ├── 页面上下文栏：当前页 / 手动刷新
│   ├── 连续消息流
│   └── 输入区
│       ├── 文本输入
│       ├── 当前来源：远端模型 / 本地 Agent
│       └── 发送 / 停止
├── 模型与 Agent 弹窗
│   ├── 远端：免费模型 / 付费模型
│   └── 本地：Bridge 检测到的 CLI Agent
└── 设置页
    ├── 连接
    ├── 外观与语言
    ├── 新建对话
    └── 关于 / 隐私 / 版本
```

明确删除：模式按钮、模式弹窗、“提问”“执行”标签和任何双入口逻辑。

## 6. 统一请求流程

```text
用户消息
  → 读取当前页面观察
  → 组合最近对话历史、用户目标、页面观察、可用工具
  → 所选模型规划下一步
      ├── finish：直接回答 / 总结 / 翻译 / 解释
      ├── scroll / fill / select：执行后重新观察
      └── click：生成批准卡片，用户批准后继续
  → 完成、停止、失败或达到步骤上限
```

智能体不得要求用户为了继续而选择“提问”或“执行”。只有模型 / Agent 来源选择由用户控制。

## 7. Bridge 边界

### 7.1 无 Bridge

- 远端任务 ID 由扩展生成。
- 目标、对话历史、步骤数、状态保存在 `chrome.storage.session`。
- 浏览器关闭后会话任务状态自然清除。
- 页面观察和动作由 `chrome.tabs` 与 `chrome.scripting` 完成。
- 推理请求由扩展直接发送给 OrcaRouter。
- 点击批准和取消都不能调用 Native Messaging。

### 7.2 有 Bridge 且使用远端模型

- 行为与无 Bridge 一致，避免让远端能力依赖本地主机。
- Bridge 可用于未来的可选历史持久化，但不得成为远端任务前置条件。

### 7.3 使用本地 Agent

- Bridge 负责发现 Codex CLI、Claude Code、Coco CLI。
- Bridge 创建本地任务、调用固定 CLI 参数、记录步骤并终止进程。
- 扩展仅传递结构化目标、有限对话历史和页面观察，不传递任意 Shell 命令。

## 8. 工具定义

远端与本地 Agent 对模型暴露相同的抽象动作：

- `finish(summary, reason)`：用于回答、总结、翻译、解释或说明无法完成。
- `scroll(direction, reason)`：滚动当前页面。
- `fill(elementId, value, reason)`：填写普通文本控件。
- `select(elementId, value, reason)`：选择普通选项。
- `click(elementId, reason)`：提出点击动作，必须等待用户批准。

工具输出必须在扩展侧重新校验。模型返回的 element ID 必须存在、可见且未禁用；敏感字段必须拒绝。

## 9. 安全规则

- 网页文本始终视为不可信数据，不能覆盖用户目标或系统安全规则。
- 禁止密码、支付信息、银行卡、验证码、CAPTCHA、身份验证密钥和文件上传。
- 禁止删除、购买、接受法律协议、发送消息和公开发布。
- 点击必须显示目标和理由，并由用户明确批准。
- 停止请求立即触发 `AbortController`，任务标记为取消，后续动作和迟到响应全部丢弃。
- 单任务最多 12 步，达到上限后停止并返回可恢复错误。

## 10. 对话与语言

- 每次新请求携带最近 12 条已完成的用户 / 助手消息。
- Orca Free 路由对历史、页面和提示词做确定性裁剪。
- 等待批准的临时消息不加入下一轮对话历史。
- `finish.summary` 和所有 `reason` 必须匹配当前界面语言。
- 新建对话清空消息、会话 ID 和草稿，但不重置模型、语言或主题。

## 11. 模型与额度

- 默认选择 `orcarouter/free`。
- 模型目录动态读取并按免费 / 付费分组。
- 免费模型不可用或内容超限时打开模型弹窗，保留用户草稿和对话。
- 远端模型可用条件：OrcaRouter 已连接且模型存在。
- 本地 Agent 可用条件：Bridge 可连接且对应 CLI 检测成功。
- Bridge 状态不得参与远端 `sourceAvailable` 计算。

## 12. 可访问性与键盘

- 使用原生 `button`、`textarea`、`dialog` 和 `select`。
- 所有图标按钮必须具备本地化可访问名称。
- 弹窗关闭后焦点返回输入框。
- 状态使用 `aria-live`，错误使用 assertive，普通状态使用 polite。
- 焦点样式在亮色、暗色和强制颜色模式下均清晰可见。
- 模型切换、批准、拒绝、停止与设置均可仅用键盘完成。

## 13. 验收标准

- [x] 主界面不存在“提问 / 执行”模式按钮和模式弹窗。
- [x] 所有输入统一发送 `run:agent`。
- [x] 统一请求携带最近对话历史。
- [x] 远端 Agent 的启动、状态、步骤、批准和取消不依赖 Bridge。
- [x] 无 Bridge 时可回答、总结、翻译并执行受约束浏览器动作。
- [x] 仅本地 CLI 选择受 Bridge 状态限制。
- [x] 输入框只保留模型 / Agent 切换与发送 / 停止按钮。
- [x] Orca Free 错误继续触发模型选择弹窗。
- [x] 六种界面语言键值完整，欢迎语不再引导模式切换。
- [x] 扩展构建、TypeScript、语言检查和 Bridge 测试通过。

## 14. 后续范围

- 流式展示模型解释与工具调用前提示。
- 基于风险而非动作类型的批准策略。
- 多标签页工具和可选页面选择器。
- 无 Bridge 的会话历史导出；有 Bridge 的可恢复历史列表。
- 工具调用时间线与可折叠观察结果。
